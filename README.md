# 👁️ Computer Vision Basics with OpenCV

Welcome to my Computer Vision repository! This project contains a collection of foundational scripts and applications built to explore the capabilities of computer vision and image processing.

## 🛠️ Technologies & Libraries Used
* **Python 3**
* **OpenCV** (`opencv-python`)
* **NumPy**

## 🚀 Included Projects

Here are some of the basic applications implemented in this repository:

1. **Interactive Paint Application:** 
   A digital drawing board built using OpenCV's GUI features. It utilizes trackbars to dynamically adjust RGB colors and brush radius in real-time, along with mouse event handling for smooth drawing.

2. **Mobile IP Camera Stream:**
   A script that connects to a mobile phone's camera over Wi-Fi (using IP Webcam) and streams the video feed directly to the computer, resizing frames for optimal display.

3. **Basic Image & Video Operations:**
   Scripts for reading, displaying, saving images, and capturing video streams from the default webcam.
